# TCL AI Launcher 0.2 — состояние сборки

26 октября 2026 года.

- Собраны исходники самостоятельного TV launcher v0.2.0 (`com.tclai.launcher`).
- Встроены четыре исходных широкоформатных JPEG обоев; «Неоновый мегаполис под луной» выбран по умолчанию. Есть выбор обоев в настройках и собственное изображение через ACTION_OPEN_DOCUMENT.
- Отдельные иконки с аниме-девушками для категорий **не создавались**. Карточки приложений показывают их стандартные значки.
- `tests/check_project.py`, `tests/check_wallpapers.py` и `tests/test_worker.mjs` пройдены.
- Android APK **не собран** и на TCL **не испытан**: в контейнере нет Android SDK/Gradle и нет доступа к внешним репозиториям для установки зависимостей.
- GitHub подключен, но доступен только существующий публичный репозиторий `VlV-spec/NovaMobile` (другой проект). Для приватного отдельного проекта нет доступного действия создания репозитория; публикация обоев в чужой публичный проект не проводилась.
- В `.github/workflows/build-apk.yml` есть GitHub Actions workflow; после загрузки исходников в отдельный репозиторий GitHub Actions может собрать debug APK, если зависимости загрузятся.
- Оригинальный Projectivy не изменяется; регистрация `HOME` отсутствует; Google Assistant не затронут.
