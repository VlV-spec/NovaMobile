# TCL AI Launcher 0.4 — независимый прототип Android TV

**Цель:** чистый и быстрый Android TV-экран для TCL G07 / Android 11, без элементов Premium, с настраиваемыми категориями и отдельным облачным AI. Создан **с нуля**; код Projectivy и его изображения сюда не скопированы. Никаких функций Premium Projectivy он не использует и не разблокирует.

## Уже реализовано в исходниках

- Лёгкий нативный интерфейс Java (без Compose/WebView и внешних Android-библиотек): четыре оригинальных аниме-обоев в неоновой эстетике, затемнение под текстом, выбор собственного изображения, цветовые акценты, фокус карточек для пульта.
- Чтение установленных TV-приложений, запуск через explicit Intent; одинаковые пакеты из TV/phone списков дедуплицируются.
- Категории: добавление, переименование, перестановка, удаление; назначение приложения выбранной категории.
- Скрытие приложений и восстановление через настройки. Удержание OK на карточке открывает выбор категории, также есть кнопка «Изменить» в каждой категории.
- Отдельный экран AI. Запрос по HTTPS к вашему Cloudflare Worker с токеном устройства, голосовой ввод через системный recognizer **если он доступен**, необязательная озвучка TTS.
- Worker (OpenAI Responses API + ограниченный набор действий управления TV) скопирован из ранее созданного прототипа и дополнен тестами.
- `android.intent.category.LEANBACK_LAUNCHER` и обычный `LAUNCHER` присутствуют; **`HOME` намеренно отсутствует**. Приложение не может само стать лаунчером по умолчанию. Projectivy и Google Assistant не меняются.

## Честный статус сборки

Исходный проект создан, XML и логика Worker проверены локально. **Настоящий Android APK ещё не собран и не испытан на телевизоре:** в текущей среде нет Android SDK/Gradle и нет доступа к репозиториям зависимостей. Сборка может выявить ошибки компиляции или UI, требующие исправления. Не выдавайте исходники за готовую прошивку.

## Сборка APK на GitHub Actions без своего ПК

1. Для самостоятельной сборки разместите проект в репозитории с папками `android/`, `worker/` и `.github/`. Для существующего NovaMobile держите проект в **отдельной папке** `tv-launcher/`, не заменяя корневой Gradle-проект NovaMobile. Ветку проекта храните отдельно.
2. Вкладка **Actions** → `Build TCL AI Launcher APK` → **Run workflow**.
3. Если сборка пройдёт, скачайте artifact `TCL-AI-Launcher-debug-apk`, внутри будет `app-debug.apk`.
4. На TCL установите через Bugjaeger либо через ПК командой `adb install -r app-debug.apk`. Проект использует самостоятельный ID `com.tclai.launcher`, оригинальный Projectivy не затронут.
5. Откройте **TCL AI Launcher** из списка приложений (пока **не** меняйте HOME).

Если GitHub Actions сообщает об ошибке, сохраните лог шага `Build debug APK` — код надо исправить, а не устанавливать случайно сгенерированные файлы.

### Сборка локально (при желании)

Откройте папку `android` в Android Studio с Android SDK Platform 35 / JDK 17. Соберите `app` → **Build APK(s)**. На Linux/macOS с установленным Gradle 8.10.2: `cd android && gradle :app:assembleDebug`. На Windows аналогично через Gradle/Android Studio. Нет Gradle Wrapper: GitHub Actions устанавливает Gradle сама.

## Настройка облачного ИИ

1. В каталоге `worker`: `npm install`, `npx wrangler login`, `npm run deploy`.
2. В Cloudflare Workers задайте **два секрета** через `npx wrangler secret put OPENAI_API_KEY` и `npx wrangler secret put DEVICE_TOKEN` (длинная случайная строка >=16 символов). Можно задать `OPENAI_MODEL` в настройках среды Worker; исходный код по умолчанию выбирает `gpt-4.1-mini`.
3. В ТВ-приложении откройте ✦ ИИ, укажите **HTTPS-URL** Worker (без `/chat`) и **DEVICE_TOKEN**, не OpenAI-ключ.
4. Микрофон не включается постоянно: отдельная кнопка вызывает доступное приложение распознавания речи. **Пульт может не передавать микрофон сторонним приложениям.** Ввод текста останется доступен.

Токен хранится в приватных SharedPreferences Android (не в хранилище с аппаратным шифрованием). Для теста допустимо, для публичного релиза нужна более строгая модель безопасности и rate limit на Worker.

## Как редактировать категории

- «☷ TCL AI» → «Добавить категорию» или «Изменить / переставить категории».
- В ряду категории «Изменить» → выбрать приложение, чтобы переместить его в ряд.
- Выделить плитку → **удержать OK** → выбрать категорию или скрыть приложение. В некоторых пультах длинное нажатие может не работать, поэтому предусмотрены обычные экранные кнопки.
- «Вернуть скрытые приложения» — обратимое действие.

## Файлы

- `android/app/src/main/java/com/tclai/launcher/MainActivity.java` — интерфейс и категории.
- `android/app/src/main/java/com/tclai/launcher/AssistantActivity.java` — AI-клиент.
- `android/app/src/main/AndroidManifest.xml` — только TV-приложение, не HOME.
- `worker/src/index.js` — серверный код Cloudflare.
- `.github/workflows/build-apk.yml` — сборка без ПК в GitHub Actions.
- `tests/` — проверки Worker и статической структуры проекта.

- Не изменяем механизм Premium и не имитируем платную лицензию.
- Не выключаем Google Assistant и не перехватываем глобальную кнопку микрофона.
- Не включаем приложение как HOME без тестов и явного решения пользователя.

## Состояние проверки сборки

В рабочем окружении проверены XML-манифест, целостность файлов проекта и Node.js тесты Worker. Проверить компиляцию Android SDK **здесь невозможно**: Gradle, Android SDK и `aapt2` отсутствуют, а сетевой доступ для их загрузки недоступен. Поэтому ZIP содержит **проект для автоматической сборки APK**, а не сам APK.

Для NovaMobile используется отдельная ветка/папка по прямому выбору пользователя. Не меняйте существующий корневой Gradle-проект NovaMobile и его pipeline.

## Новое в 0.2: фон без лишних значков

В настройках есть **«Обои главного экрана»**. Доступны четыре оригинальные панорамы, по умолчанию — согласованный «Неоновый мегаполис под луной». Дополнительно можно выбрать собственное изображение через системный файловый менеджер (если он есть на ТВ). Изображения находятся в `drawable-nodpi`, сохранены в JPEG для экономии памяти. На TCL 2 GB одновременно загружается только выбранный фон, меню накладывает мягкий затемняющий слой слева. Категории остаются обычными строками приложений — **обои не используются как иконки категорий**.

## Новое в 0.3: экранная шестерёнка и проверка AI

- Одно нажатие **OK на экранной кнопке «⚙ Android»** открывает стандартные настройки Android TV (`Settings.ACTION_SETTINGS`), с запасным вариантом пакета ТВ-настроек.
- **Долгое OK на этой экранной кнопке** открывает два ползунка: яркость **обоев** (40–160%) и насыщенность **обоев** (0–200%). Эти ползунки используют `ColorMatrixColorFilter` только на фоне нашего лаунчера, не меняют аппаратную яркость TCL или глобальную насыщенность Android. Кнопки «Сохранить»/«Отмена»/«Сбросить» работают с локальными настройками.
- Если на пульте длинное нажатие не срабатывает, используйте **«☷ TCL AI» → «Яркость и насыщенность фона»**. Меню «☷ TCL AI» также содержит категории, скрытые приложения, смену обоев и ИИ.
- Экран ИИ содержит кнопку **«Проверить сервер»**. Она проверяет доступность `GET /health` без раскрытия токена. Это **не проверка наличия действующего OpenAI-ключа**; для полного теста нужно настроить Worker/секреты и послать сообщение.
- Сохраняются четыре проверенных обоев из 0.2; новые изображения не генерируются. По умолчанию — согласованный ночной фиолетовый мегаполис.
- Удержание кнопки Settings на **физическом пульте** может обрабатываться TCL/Google и не гарантировано доступно стороннему лаунчеру. Реализовано короткое/долгое нажатие именно **экранной кнопки «⚙ Android»**.


## 0.4 — Happ VPN и Kino

Индикатор на верхней панели показывает наличие системного VPN через ConnectivityManager (не читает конфиги Happ; статус не доказывает идентичность провайдера VPN). Нажатие открывает Happ, если оно установлено. При возвращении в лаунчер статус обновляется.

Полка «Продолжить просмотр · Kino» отображает созданные пользователем карточки сериалов с обложками, выбранными из файлового менеджера Android (SAF). Воспроизведение начинается в Kino: прямой запуск конкретной серии не поддерживается без документированного механизма deep link. Данные просмотров из Kino автоматически не считываются, никаких вымышленных названий/эпизодов.
